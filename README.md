# 💵 Expense Splitter (حاسبة تقسيم المصروفات)

A simple and practical Python script to calculate and split expenses evenly among friends.

## 📝 About (نبذة عن المشروع)
This program takes the names of friends, prompts for the amount spent by each person, calculates the total expenses, and divides the total amount equally among everyone.

## 🛠️ Concepts & Technologies Used (التقنيات والمفاهيم المستخدمة)
* **Python 3**
* **Lists & Methods:** Utilizing `append()` to store data.
* **Loops:** Using `for` loops to iterate through inputs.
* **String Manipulation:** Using `split()` to process user input names.

## 🚀 How to Run (طريقة التشغيل)
1. Ensure Python is installed on your device.
2. Download the `Expense_Splitter.py` file.
3. Run the script via your terminal or command line:
   ```bash
   python Expense_Splitter.py
